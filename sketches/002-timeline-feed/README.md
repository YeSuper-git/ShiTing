## Variant: 时间线聚合

### Design stance
左侧导航 + 右侧时间线，所有类别按到期时间统一线性排列。

### Key choices
- Layout: 左侧固定导航 + 右侧滚动内容区
- Typography: 系统字体，时间线分组标题加粗
- Color: 白色背景，状态色：红/橙/绿
- Interaction: 时间线按日期分组（已过期/今天/3天内/7天内/30天内/更久），筛选标签切换

### Trade-offs
- Strong at: 信息密度高，所有快到期项目一目了然
- Weak at: 需要点击左侧切换类别，不能同时看多个类别

### Best for
- 有大量记录需要管理的用户
- 关注"最近要到期什么"的场景

### 首页展示数量建议
时间线默认显示全部，可按状态筛选。
