## Variant: 卡片式仪表盘

### Design stance
四宫格布局，每个卡片展示一个类别的快到期项目，一目了然。

### Key choices
- Layout: 2×2 网格，每格一个类别
- Typography: 系统字体，14-15px 正文
- Color: 浅灰背景 + 白色卡片，状态色：红/橙/绿
- Interaction: 卡片内点击"查看全部"进入详情，点击"添加"直接打开对应类别的表单

### Trade-offs
- Strong at: 首页总览，快速了解各类别状态
- Weak at: 信息密度较低，需要滚动查看更多

### Best for
- 喜欢仪表盘风格的用户
- 需要快速总览各类别状态的场景

### 首页展示数量建议
每类 3-5 条，四宫格卡片高度一致。
