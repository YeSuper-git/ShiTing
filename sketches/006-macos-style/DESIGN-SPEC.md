# 时停 - 设计规范

> 基于 macOS 26 原生应用风格，参考 Apple HIG 设计系统

---

## 1. 设计理念

- **克制、简洁、有意义** — 界面退后，内容优先
- **系统原生感** — 用户感觉这是 macOS 内置应用
- **毛玻璃效果** — 仅在导航栏和侧边栏使用，不滥用

---

## 2. 颜色系统

### 主色
| Token | 值 | 用途 |
|-------|-----|------|
| `--accent` | `#007AFF` | 主按钮、链接、激活态 |
| `--accent-hover` | `#0056CC` | 按钮悬浮 |
| `--accent-active` | `#0052B3` | 按钮按下 |

| Token | 值 | 用途 |
|-------|-----|------|

| `--warning` | `#FF9500` | 即将到期、警告 |

## 7. 毛玻璃效果

```css

backdrop-filter: blur(40px) saturate(180%);

/* 工具栏 */
backdrop-filter: blur(20px) saturate(180%);

/* 弹窗背景 */
backdrop-filter: blur(8px);
```

## 9. 组件规范

### 按钮
- 主按钮：`#007AFF` 背景，白色文字，8px 圆角
- 幽灵按钮：透明背景，`#007AFF` 文字
- 高度：36px

### 卡片
- 背景：`rgba(255, 255, 255, 0.8)`
- 圆角：16px
- 边框：`1px solid rgba(0, 0, 0, 0.06)`
- 悬浮时上移 2px + 加深阴影

### 列表行
- 高度：64px
- 分割线从 52px 处开始
- 悬浮背景：`rgba(0, 0, 0, 0.03)`

### 状态角标
- 已过期：红色背景 `rgba(255, 59, 48, 0.12)`，红色文字
- 即将到期：橙色背景 `rgba(255, 149, 0, 0.12)`，橙色文字
- 正常：绿色背景 `rgba(52, 199, 89, 0.12)`，绿色文字

---

## 10. 可访问性

- 正文对比度 ≥ 4.5:1
- 大文字对比度 ≥ 3:1
- 焦点状态：`2px solid #007AFF` 轮廓
- 支持 `prefers-reduced-motion`
