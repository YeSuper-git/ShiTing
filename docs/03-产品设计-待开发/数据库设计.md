# 时停 - 数据库设计

## 概述

- 数据库：SQLite
- 存储位置：`~/Library/Application Support/com.shiting.app/shiting.db`（macOS）
- ORM：rusqlite

---

## 表结构

### 1. games - 游戏表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | UUID |
| name | TEXT NOT NULL | 游戏名称 |
| icon | TEXT | 图标路径 |
| created_at | TEXT | 创建时间 |

### 2. game_records - 游戏消费记录表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | UUID |
| game_id | TEXT NOT NULL | 关联游戏 |
| type | TEXT NOT NULL | 记录类型（月卡/大月卡/通行证） |
| purchase_date | TEXT | 购买日期 |
| start_date | TEXT | 生效日期 |
| expire_date | TEXT | 到期日期 |
| amount | REAL | 消费金额 |
| note | TEXT | 备注 |
| images | TEXT | 图片路径（JSON数组） |
| created_at | TEXT | 创建时间 |

### 3. hardware_types - 硬件类型表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | UUID |
| name | TEXT NOT NULL | 类型名称 |
| sort_order | INTEGER | 排序 |

### 4. hardwares - 硬件记录表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | UUID |
| type_id | TEXT NOT NULL | 关联类型 |
| name | TEXT NOT NULL | 商品名称 |
| brand | TEXT | 品牌 |
| purchase_date | TEXT | 购买日期 |
| purchase_channel | TEXT | 购买渠道 |
| warranty_months | INTEGER | 质保月数 |
| warranty_expire | TEXT | 质保到期日 |
| price | REAL | 购买价格 |
| order_no | TEXT | 订单号 |
| note | TEXT | 备注 |
| images | TEXT | 图片路径（JSON数组） |
| created_at | TEXT | 创建时间 |

### 5. consumable_types - 耗材类型表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | UUID |
| name | TEXT NOT NULL | 类型名称 |
| sort_order | INTEGER | 排序 |

### 6. consumables - 耗材记录表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | UUID |
| type_id | TEXT NOT NULL | 关联类型 |
| name | TEXT NOT NULL | 耗材名称 |
| brand | TEXT | 品牌/型号 |
| purchase_date | TEXT | 购买日期 |
| expire_date | TEXT | 保质期至 |
| usage_duration_days | INTEGER | 建议使用天数 |
| start_use_date | TEXT | 开始使用日期 |
| expected_end_date | TEXT | 预计用完日期 |
| stock_qty | INTEGER | 库存数量 |
| single_duration_days | INTEGER | 单个可用天数 |
| max_duration_days | INTEGER | 最大可用天数 |
| note | TEXT | 备注 |
| images | TEXT | 图片路径（JSON数组） |
| created_at | TEXT | 创建时间 |

### 7. medicine_categories - 药品分类表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | UUID |
| name | TEXT NOT NULL | 分类名称 |
| sort_order | INTEGER | 排序 |

### 8. medicines - 药品记录表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | UUID |
| category_id | TEXT NOT NULL | 关联分类 |
| name | TEXT NOT NULL | 药品名称 |
| specification | TEXT | 规格 |
| purchase_date | TEXT | 购买日期 |
| expire_date | TEXT | 有效期至 |
| indication | TEXT | 适应症 |
| usage_dosage | TEXT | 用法用量 |
| contraindication | TEXT | 禁忌/注意事项 |
| storage_condition | TEXT | 存储条件 |
| remaining_qty | TEXT | 当前余量 |
| note | TEXT | 备注 |
| images | TEXT | 图片路径（JSON数组） |
| created_at | TEXT | 创建时间 |

---

## 预设数据

### 硬件类型
- 显卡、显示器、主板、CPU、内存、硬盘、电源、机箱、外设、其他

### 耗材类型
- 净水滤芯、空气滤芯、电池、灯泡、清洁用品、其他

### 药品分类
- 感冒发烧、肠胃消化、外伤消毒、慢性病、维生素保健、儿童用药、其他
