# 时停 (ShiTing) - 需求文档

## 项目概述

**项目名称**：时停 (ShiTing)  
**项目定位**：本地时间记录与提醒工具  
**目标平台**：Windows（优先）、macOS  
**技术栈**：Tauri 2.0 + React + TypeScript + SQLite  
**UI 风格**：简洁风格（Shadcn UI）

---

## 数据结构设计

### 游戏类 (Game)

**层级关系**：游戏 → 消费记录

**游戏表 (games)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | string | 游戏名称（原神、崩铁等） |
| icon | string? | 游戏图标（可选） |
| created_at | datetime | 创建时间 |

**消费记录表 (game_records)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| game_id | UUID | 关联游戏 |
| type | string | 记录类型（月卡/大月卡/通行证/会员等） |
| purchase_date | date | 购买日期 |
| start_date | date | 生效日期 |
| expire_date | date | 到期日期 |
| amount | decimal | 消费金额（元） |
| note | string? | 备注 |
| images | string[] | 图片路径列表 |

**示例**：
```
原神
├── 月卡 2026-05-01 ~ 2026-06-01  ¥30
├── 月卡 2026-06-01 ~ 2026-07-01  ¥30
└── 大月卡 2026-06-15 ~ 2026-07-15 ¥68
```

---

### 硬件质保类 (Hardware)

**支持自定义类型分类**

**类型表 (hardware_types)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | string | 类型名称（显卡、显示器、外设等） |
| sort_order | int | 排序 |

**硬件记录表 (hardwares)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| type_id | UUID | 关联类型 |
| name | string | 商品名称 |
| brand | string? | 品牌 |
| purchase_date | date | 购买日期 |
| purchase_channel | string? | 购买渠道 |
| warranty_months | int | 质保月数 |
| warranty_expire | date | 质保到期日（自动计算） |
| price | decimal? | 购买价格 |
| order_no | string? | 订单号 |
| note | string? | 备注 |
| images | string[] | 图片路径列表 |

**预设类型**：显卡、显示器、主板、CPU、内存、硬盘、电源、机箱、外设、其他

---

### 家用耗材类 (Consumable)

**支持自定义类型分类**

**类型表 (consumable_types)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | string | 类型名称（滤芯、电池、灯泡等） |
| sort_order | int | 排序 |

**耗材记录表 (consumables)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| type_id | UUID | 关联类型 |
| name | string | 耗材名称 |
| brand | string? | 品牌/型号 |
| purchase_date | date | 购买日期 |
| expire_date | date? | 保质期至 |
| usage_duration_days | int | 建议使用天数 |
| start_use_date | date? | 开始使用日期 |
| expected_end_date | date | 预计用完日期（自动计算） |
| stock_qty | int | 库存数量（未开封） |
| single_duration_days | int | 单个可用天数 |
| max_duration_days | int | 最大可用天数（自动计算） |
| note | string? | 备注 |
| images | string[] | 图片路径列表 |

**预设类型**：净水滤芯、空气滤芯、电池、灯泡、清洁用品、其他

---

### 药品管理类 (Medicine)

**分类 + 单独记录**

**分类表 (medicine_categories)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | string | 分类名称 |
| sort_order | int | 排序 |

**药品记录表 (medicines)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| category_id | UUID | 关联分类 |
| name | string | 药品名称 |
| specification | string? | 规格（0.2g×24片） |
| purchase_date | date? | 购买日期 |
| expire_date | date | 有效期至 |
| indication | string? | 适应症 |
| usage_dosage | string? | 用法用量 |
| contraindication | string? | 禁忌/注意事项 |
| storage_condition | string? | 存储条件 |
| remaining_qty | string? | 当前余量（如：18片、半瓶） |
| note | string? | 备注 |
| images | string[] | 图片路径列表 |

**预设分类**：感冒发烧、肠胃消化、外伤消毒、慢性病、维生素保健、儿童用药、其他

**示例**：
```
感冒发烧
├── 布洛芬缓释胶囊  有效期至 2027-03  余量: 18粒
├── 感冒灵颗粒      有效期至 2026-12  余量: 5袋
└── 连花清瘟胶囊    有效期至 2027-06  余量: 24粒
```

## 通用功能

### 到期提醒
- 应用启动时检查所有即将到期的项目
- 首页醒目标记过期/临期项目

### 图片支持
- 每条记录可附加多张图片
- 图片存储在本地应用数据目录
- 支持拖拽上传和点击选择

### 类型管理
- 硬件、耗材、药品支持自定义类型/分类
- 可增删改类型（预设默认类型）

### 数据管理
- 本地 SQLite 存储
- 支持导出/导入（JSON 格式）
